Privacy Policy

Last updated: October 6, 2026

This policy describes the TheoryLabs website as it actually works today. TheoryLabs is a free, non-commercial project run by an individual (“the site operator”).

What the website collects from visitors

  • No accounts. There is no sign-up, sign-in or profile, and no form that asks for personal information.
  • No cookies and no browser storage. The site sets no cookies and does not use local storage or similar technologies.
  • No analytics, tracking or advertising. The pages load no third-party scripts, fonts, trackers or ads; every file comes from the TheoryLabs site itself.
  • No connection to your Riot account. The site does not use Riot Sign On and cannot see your account or your games.

Hosting and server logs

The website is hosted by a third-party hosting provider (currently Render). Like any web server, the host receives standard request information, such as your IP address, browser user agent, the page requested and the time, and may keep it in server and security logs under its own privacy policy. TheoryLabs does not use this information to identify, profile or track visitors.

Riot Games data

TheoryLabs uses the Riot Games API to retrieve ranked TFT match data and turns it into aggregate statistics about champions, items, traits and boards. The website shows only aggregates across many boards: it never displays player names, Riot IDs or other player identifiers, and it offers no way to look up a player.

To sample matches without collecting the same ones twice, the data pipeline keeps Riot's anonymous player identifiers (PUUIDs) of the sampled ladder players in an internal collection log. These are not published, not sold and not shared, and are used only for that purpose. Data obtained from Riot is handled in line with Riot's developer policies.

Your choices and contact

Because the website collects no personal data from visitors, there is nothing to access or delete for site visits. For questions about this policy or about match data, contact the site operator through the project's public repository: github.com/alienheadbill/tft-theorylab (please do not post personal information in a public issue).

Changes

If the site starts collecting anything new, this page will be updated before that happens, and the date above will change.
